# 王阳明·普通人思维蒸馏工具

[WorkBuddy Skill](https://www.codebuddy.cn) · MIT License · v1.3.1

> 借鉴阳明心学"反求诸己、致良知"的方法论，通过结构化问卷帮助用户发现自己内在的思维框架与表达风格，生成专属的"思维镜像"。

---

## 快速开始

### 激活方式

在 WorkBuddy 对话中提及以下内容即可激活：

- "蒸馏我"、"蒸馏自己"、"认识自己"、"王阳明"、"向内看"
- "思维镜像"、"普通人蒸馏"、"我的视角"、"提取我的风格"
- "我是一个怎样的人"、"照见自我"

### 前提条件

- 预留约 30 分钟完整参与
- 准备一支笔和一张纸（可选，用于记录思考）

## 工作原理

### 三阶蒸馏法

```
┌─────────────────────────────────────────────────────────┐
│  Phase 1：观点探测（~10分钟）                              │
│  38道选择题，测量价值观、人格特质、认知模式                │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 2：情境反应（~15分钟）                              │
│  7道情境题 + 追问，探测思维框架与决策模式                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 3：语料采样（~5分钟）                               │
│  2-3个写作任务，采集表达风格DNA                            │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  [可选] 素材导入                                           │
│  导入已有文章/论文，直采真实表达风格                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  AI 分析与校准                                             │
│  生成初稿 → 校准测试 → 进化反馈 → 安装                      │
└─────────────────────────────────────────────────────────┘
```

### 双模式蒸馏

| 模式 | 触发条件 | 分析重点 |
|------|----------|----------|
| 问卷主导 | 无素材或素材少 | 三阶问卷为主，素材补充 |
| 素材主导 | 有丰富的文章/论文 | 素材分析为主，问卷补充价值观 |

## 问卷维度

| 维度 | 测量内容 |
|------|----------|
| 自我认知 | 对自身的了解程度 |
| 归因模式 | 内因/外因倾向 |
| 风险偏好 | 激进/保守程度 |
| 人际取向 | 集体/个人倾向 |
| 认知风格 | 直觉/分析偏好 |
| 价值排序 | 核心价值取舍 |
| 大五人格 | 开放性/尽责性/情绪稳定性 |
| 动机结构 | 自主感、能力感、关联感 |

## 模块说明

### analyzer/ — 分析与评分引擎

规则计算 + LLM 混合评分系统：

- `phase1_scorer.py`：Phase 1 计分与雷达图数据构建
- `phase2_analyzer.py`：情境题分析与动机探测
- `phase3_analyzer.py`：语料采样分析
- `integrator.py`：三阶段整合与心智模型构建
- `calibration.py`：校准测试问题生成与准确度计算

### evolution/ — 进化反馈系统

借鉴阳明心学"反求诸己"理念，通过用户评分持续优化问卷题目：

- `collectors/feedback_collector.py`：用户评分收集
- `analyzers/stats_analyzer.py`：题目区分度统计分析
- `reports/report_generator.py`：改进报告生成
- `config.json`：进化模块配置

### generator/ — Skill 生成引擎

- `skill_generator.py`：`DistillationSession` 管理三阶段数据 → 分析 → 整合 → Skill 生成

### questionnaire/ — 结构化题库

- `phase1.json`：38题观点探测问卷
- `phase2.json`：7场景情境题（含条件追问配置）
- `phase3.json`：3个写作任务

## 输出

生成可安装的 WorkBuddy Skill，包含：

- 核心心智模型（3-5个）
- 决策启发式（5-8条）
- 表达DNA（句式/用词/修辞偏好）
- 价值观雷达图
- 典型场景反应

## 局限性

| 局限 | 说明 | 应对措施 |
|------|------|----------|
| 自我认知偏差 | 人对自己的判断不一定准确 | Phase 2 情境追问交叉验证；素材导入提供真实样本 |
| 社会赞许效应 | 可能按"应该"而非"真实"回答 | F1 强迫排序含陷阱项；F2 内隐两难选择 |
| 情境覆盖有限 | 题目无法覆盖所有思维模式 | 可选追加定向问题；素材导入补充 |
| 表达失真风险 | 文字表达与内心想法可能有差距 | Phase 3 语料采样直接采集真实写作风格 |
