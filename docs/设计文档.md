# 王阳明·普通人思维蒸馏工具设计文档

> 版本：v1.2.0
> 更新时间：2026-04-26
> 借鉴阳明心学"反求诸己、致良知"的方法论，通过结构化问卷帮助用户发现自己内在的思维框架与表达风格。

---

## 一、工具定位

**王阳明**是一个普通人思维蒸馏工具，帮助用户通过结构化问卷发现自己内在的思维框架与表达风格，生成专属的"思维镜像"Skill。

### 适用人群

- 想更深入了解自己的思维模式和表达风格
- 好奇自己在不同场景下会如何决策和表达
- 希望提取自己的思维框架，生成专属 AI 视角

### 与女娲的区别

| 工具 | 目标对象 | 数据来源 |
|------|----------|----------|
| 女娲（huashu-nuwa） | 有网络数据的公众人物 | 自动抓取公开数据 |
| 王阳明 | 没有网络数据的普通人 | 结构化问卷 + 素材导入 |

## 三、工作原理

### 3.1 三阶蒸馏法

```
┌─────────────────────────────────────────────────────────┐
│  Phase 1：观点探测（~12分钟）                              │
│  36-39道选择题，测量价值观、人格特质、认知模式              │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 2：情境反应（~15分钟）                              │
│  5道情境题 + 追问，探测思维框架与决策模式                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 3：语料采样（~5分钟）                               │
│  2-3个写作任务，采集表达风格DNA                            │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  [可选] Phase 4.5：素材导入                                │
│  导入已有文章/论文，直采真实表达风格                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  AI分析与校准                                             │
│  生成初稿 → 用户校准 → 确认 → 安装                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 双模式蒸馏

| 模式 | 触发条件 | 分析重点 |
|------|----------|----------|
| 问卷主导 | 无素材或素材少 | 三阶问卷为主，素材补充 |
| 素材主导 | 有丰富的文章/论文 | 素材分析为主，问卷补充价值观 |

如果你有自己写过的论文、公众号文章、笔记，可以一并提供——真实的表达比即兴回答更能体现你的风格。

## 四、问卷维度

| 维度 | 测量内容 | 示例问题 |
|------|----------|----------|
| 自我认知 | 对自身的了解程度 | "你最常被身边的人用什么词形容？" |
| 归因模式 | 内因/外因倾向 | "成功后，你更愿意归因于？" |
| 风险偏好 | 激进/保守程度 | "面对50%概率赢100万，你会？" |
| 人际取向 | 集体/个人倾向 | "你更看重友谊中的什么？" |
| 认知风格 | 直觉/分析偏好 | "重大决策时你更依赖？" |
| 价值排序 | 核心价值取舍 | "自由、成就感、关系、安全排序？" |
| 大五人格 | 开放性/尽责性/情绪稳定性 + 内隐价值 | "强迫排序6项，揭示真实而非'应该'的优先项" |
| 动机结构 | SDT三要素：自主感、能力感、关联感 | "做事的主要动力来源是什么？" |

## 五、典型情境

1. **利益冲突**：朋友借钱但用途不认同
2. **权威挑战**：发现领导决策有问题
3. **道德困境**：同事晋升材料造假
4. **长期选择**：稳定大公司 vs 成长小公司
5. **认知冲突**：遇到相反但有力的论证
6. **依恋压力（可选二选一）**：
   - S6A亲密关系版：恋人突然变得冷淡
   - S6B家庭版：父母突然对你变得冷淡

## 六、素材导入（可选）

如果你有自己写过的论文、公众号文章、笔记，可以直接导入分析。

### 6.1 支持类型

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 论文/报告 | PDF或Word文档 | 解析正文，提取语言风格 |
| 文章/博客 | 公众号、知乎等链接 | 抓取正文内容 |
| 笔记/随笔 | Markdown或纯文本 | 直接分析 |
| 语音转文字 | 录音转写的文稿 | 分析口语化表达 |

### 6.2 导入方式

- 上传文件（拖拽或选择）
- 提供链接
- 直接粘贴文字
- 从Obsidian/IMA笔记中选择

### 6.3 分析内容

- **句式特征**：短句/长句/从句使用偏好
- **用词风格**：学术化/口语化/网络化
- **逻辑结构**：先结论/先铺垫/并列式
- **标志性表达**：口头禅、常用句式、金句
- **修辞手法**：比喻/举例/排比使用频率

### 6.4 整合方式

- 素材分析结果与问卷结果交叉验证
- 问卷结果补充价值观维度
- 素材结果主导表达风格维度

## 八、表达DNA编码指南

### 8.1 句式偏好标签

| 标签 | 说明 |
|------|------|
| 短句为主 | 简洁有力，信息密度高 |
| 长句为主 | 逻辑严密，层层递进 |
| 从句多 | 结构复杂，表达谨慎 |
| 问句多 | 启发式表达，引导思考 |
| 设问句多 | 自问自答式表达 |
| 陈述句为主 | 克制情感表达 |

### 8.2 用词特点标签

| 标签 | 说明 |
|------|------|
| 学术化 | 术语、专业概念多 |
| 口语化 | 日常用语、俚语多 |
| 网络化 | 梗、网络用语多 |
| 书面化 | 正式、规范用语多 |

### 8.3 标志性表达记录

- 常用句式（如"首先...其次...最后..."）
- 金句（如有独特表达习惯）
- 口头禅
- 特殊标点使用习惯

## 九、用户校准机制

### 9.1 风格测试

用新风格生成一段话，让用户打分（1-10分），指出需要调整的地方。

### 9.2 修改

根据反馈调整表达DNA和心智模型。

### 9.3 追加问答

如有需要，追加3-5道针对性问题，进一步校准。

## 十、局限性

| 局限 | 说明 | 应对措施 |
|------|------|----------|
| 自我认知偏差 | 人对自己的判断不一定准确 | Phase 2情境追问交叉验证；素材导入提供真实表达样本 |
| 社会赞许效应 | 可能按"应该"而非"真实"回答 | G4强迫排序（6项，陷阱项）；G5内隐两难选择 |
| 情境覆盖有限 | 题目无法覆盖所有思维模式 | 可选Phase 4.5追加定向问题；素材导入补充 |
| 表达失真风险 | 文字表达与内心想法可能有差距 | Phase 3语料采样直接采真实写作风格 |

## 十一、理论基础

本工具的问卷设计借鉴了多个成熟的心理学理论框架，旨在更精准地探测真实的思维与动机结构。

### 11.1 大五人格（Big Five / OCEAN）

大五人格模型是当代人格心理学最具共识的理论框架，包含五个核心维度：

| 维度 | 全称 | 高分特征 |
|------|------|----------|
| O | Openness（开放性） | 好奇心强、喜欢新事物、抽象思维 |
| C | Conscientiousness（尽责性） | 自律、有条理、责任感强 |
| E | Extraversion（外向性） | 社交能量高、活跃、喜欢刺激 |
| A | Agreeableness（宜人性） | 合作、同理心强、信任他人 |
| N | Neuroticism（神经质） | 情绪敏感、焦虑倾向（低分=情绪稳定） |

**本工具对应改进点**：

- G1：开放性（O）——哲学/艺术兴趣探测
- G2：尽责性（C）——计划性与自我管理
- G3：神经质（N）——情绪稳定性（非诊断性问法）

### 11.2 内隐关联理论（IAT / 强迫排序）

**问题**：直接问"你最看重什么"，人们往往按"社会期望"回答，而非真实驱动。

**解决方案**：强迫排序（Forced Ranking）要求对6个选项排出唯一顺序，其中混入两个"社会赞许陷阱项"（被尊重、被需要），通过对比揭示真实的潜意识优先项。

### 11.3 依恋理论（Attachment Theory）

依恋理论（Bowlby/Ainsworth）揭示了人在亲密关系中的两种核心焦虑：

- **焦虑型依恋**：害怕被抛弃，反复确认对方态度
- **回避型依恋**：害怕被依赖，压抑情感需求
- **安全型依恋**：能直接表达需求，也能接受不确定性

**本工具对应改进点**：

- S6A（恋人版）/ S6B（家人版）：依恋压力场景探测
- 分析框架新增 attachment_style 维度

### 11.4 自我决定理论（SDT）

自我决定理论（Deci & Ryan）认为人有三种基本心理需求：

- **自主感（Autonomy）**：做事的内在驱动 vs 外部压力
- **能力感（Competence）**：通过挑战证明自己 vs 轻松搞定
- **关联感（Relatedness）**：人与人深度连接的需求

**本工具对应改进点**：

- H1：自主感——内在驱动 vs 外部驱动
- H2：能力感——挑战型 vs 认可型 vs 协作型
- H3：关联感——高社交需求 vs 享受独处

### 11.5 动机结构追问（九型人格逻辑）

Phase 2所有情境的追问池统一增加了动机追问，借鉴九型人格"追问驱动"的理念：

> "你做出这个选择，背后最深的驱动是什么？"

这个问题迫使回答者从表层行为进入深层动机，揭示行为背后的真实需求——是恐惧驱动（防御性动机）、还是价值驱动（成长性动机）、还是习惯驱动（惯性动机）。

### 11.6 理论整合对照

| 理论 | 解决的问题 | 本工具对应 |
|------|----------|-----------|
| 大五人格 | 人格特质全面覆盖 | G1-G3 |
| 强迫排序 | 社会赞许效应 | G4 |
| 内隐两难 | 价值观隐性偏好 | G5 |
| SDT | 动机结构深层探测 | H1-H3 |
| 依恋理论 | 亲密关系反应模式 | S6A/S6B |
| 九型追问 | 行为背后的真实驱动 | 所有情境追问池 |
